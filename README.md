## 技术架构

炫连VPN 基于 Electron + React + TypeScript 构建

### 前端技术栈

- **React 19** - 用户界面框架
- **TypeScript** - 类型安全的 JavaScript
- **HeroUI (NextUI)** - UI 组件库
- **Tailwind CSS** - 原子化 CSS 框架
- **Monaco Editor** - 代码编辑器

### 后端技术栈

- **Electron** - 应用主进程
- **高性能加速引擎** - 网络优化核心

## 快速开始

1. **克隆项目**

```bash
git clone https://github.com/chunkburst/xuanlian-vpn.git
cd xuanlian-vpn
```

2. **安装依赖**

```bash
pnpm install
```

3. **启动开发服务器**

```bash
pnpm dev
```

## 构建发布

```bash
pnpm build:win    # 构建 Windows 版本
pnpm build:mac    # 构建 macOS 版本
pnpm build:linux  # 构建 Linux 版本
```
